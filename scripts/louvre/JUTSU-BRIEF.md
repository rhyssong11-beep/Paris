# 루브르 박물관 재제작 작업 지시서 (Claude + Higgsfield 3D Jutsu)

이 문서는 **claude.ai**에서 Higgsfield 커넥터로 루브르를 새로 만들 때 쓰는 지시서입니다.
결과물(3D Jutsu 프로젝트와 텍스처)은 이 저장소의 Claude Code 세션이 받아 뷰어에 넣습니다.

- 목표: **멀리서 본 모습이 실사처럼 보이는 루브르.** 외관과 피라미드 아래 나폴레옹 홀까지 포함합니다.
- 범위 밖: 사람 눈높이에서 보는 디테일, 전시실 내부, 역피라미드(카루젤 쇼핑몰)

---

## 0. 시작 전에 확인할 것

1. **claude.ai 모델 선택기에서 Fable 5.2를 고릅니다.** 참고한 Higgsfield 글("Fable 5.2 Designed a Four-Room Apartment in Code")에서 Fable 5.2는 Higgsfield의 이미지 생성 모델이 아닙니다. 3D Jutsu(호스팅 블렌더)에 `bpy` 코드를 써서 장면을 짓는 **채팅 모델**입니다. 그래서 claude.ai 채팅 자체를 Fable 5.2로 열어야 합니다.
2. Higgsfield 커넥터를 연결하고 `balance`를 호출합니다. (2026-11-11 확인 결과: Ultra 플랜, 크레딧 2)
3. **무제한(unlim)이 적용되는 범위:** 2026-11-11에 확인한 무제한 대상은 이미지(GPT Image 2.6/2.5/2, Nano Banana Pro/2/2.1, Seedream 5.5/5.0 Pro, Soul 2.0), 영상(Seedance 2.0/2.5), 오디오 모델뿐입니다. **3D Jutsu의 `scene_builder_3d_run_python`(블렌더 실행)은 이 목록에 없습니다.** 첫 작은 작업 하나를 실행한 뒤 `transactions`로 크레딧이 빠졌는지 확인하세요. 빠졌다면 작업을 멈추고 상의합니다.
   - `scene_builder_3d_generate_angles`와 `scene_builder_3d_generate_video`는 크레딧을 쓰므로 **이 작업에서는 쓰지 않습니다.**
4. claude.ai 채팅에서 처음 할 일: `get_preset_instructions { preset: "/3d-jutsu" }`를 부르고, 이어서 참고 문서 세 개를 읽습니다. `/3d-jutsu/references/scene-building`, `/3d-jutsu/references/composition-modeling`, `/3d-jutsu/references/lookdev-lighting`

## 1. 3D Jutsu 런타임의 제약 (설계에 반영됨)

- 블렌더 `bpy` 5.2이고 화면 없이(headless) 돌아갑니다. 작업 한 번에 **약 5분**, 코드는 256 KiB까지입니다. 그래서 작업을 작게 나눕니다.
- **네트워크가 없습니다.** AI로 만든 텍스처 이미지를 블렌더 안으로 가져올 수 없습니다.
  → AI 텍스처는 **뷰어(three.js)가 재료 이름을 보고 입힙니다.** 노트르담과 같은 방식입니다.
- **절차적 셰이더와 월드 조명은 GLB로 넘어가지 않습니다.** GLB에 남는 것은 Principled BSDF의 기본값(색, 거칠기, 금속성), UV, 정점 색(Color Attribute)입니다.
- Area 라이트는 GLB와 장면 미리보기에서 빠집니다. 미리보기용 조명은 Sun, Spot, Point만 씁니다.
- `generate_3d`(이미지 → 메시)는 큰 건물에서 형태가 뭉개지므로 쓰지 않습니다.

## 2. 실사 느낌을 내는 방법 (실시간 웹 뷰어 기준)

웹 뷰어는 경로 추적(path tracing)을 할 수 없습니다. 그래서 실사 느낌을 아래 다섯 가지로 나눠서 만듭니다.

| 요소 | 담당 | 방법 |
|---|---|---|
| 형태(실루엣) | Jutsu | 맨사드 지붕, 도머 창, 굴뚝, 파빌리옹 돔과 랜턴, 깊은 코니스, 콜로나드 기둥을 **실제 형상**으로 만듭니다. 멀리서는 실루엣과 그림자가 실사 느낌의 대부분을 만듭니다. |
| 차폐광(AO) | Jutsu | Cycles로 AO를 **정점 색(Color Attribute `AO`)에 bake**합니다. UV가 필요 없고 GLB로 넘어갑니다. 처마 밑, 창 깊이, 안뜰 모서리가 어두워져 입체감이 생깁니다. |
| 재질 | Higgsfield 무제한 이미지 | 석재, 슬레이트 지붕, 창이 들어간 외벽 한 칸을 **이어 붙일 수 있는(seamless) PBR 텍스처**로 만듭니다(아래 5절). |
| UV | Jutsu | 모든 메시에 **1 UV 단위 = 1 m**인 큐브 투영 UV를 줍니다. 외벽 한 칸 텍스처용으로는 외벽 면에 `UVMap_Bay`(가로 6.2 m = 1 단위, 세로 처마 높이 = 1 단위)를 따로 줍니다. |
| 빛과 대기 | Claude Code | HDR 하늘 환경맵, 태양 그림자, AgX 톤매핑, 공기 원근감(안개)을 맡습니다. 밤 조명은 기존 뷰어 기능을 씁니다. |

## 3. 좌표계와 배치 (기존 뷰어·주변 도시·테스트와 반드시 맞춰야 함)

- 단위는 **미터**입니다. 원점은 **메인 피라미드 바닥 중심**입니다. +x는 동쪽(쿠르 카레 쪽), +z는 남쪽(센강 쪽), +y는 위입니다.
  - 블렌더는 Z가 위쪽이지만 GLB로 내보내면 Y가 위가 됩니다. 블렌더 안에서는 **+X 동쪽, −Y 남쪽**(GLB에서 +z가 됨), +Z 위로 작업하세요.
- 실제 루브르의 축은 조금 틀어져 있지만 **정동서 축으로 곧게 맞춥니다.**
- 주변 도시 코드는 **x −520~330, z −160~158**만 비워 둡니다. 모델은 이 안에 들어가야 합니다(카루젤 정원 포함).

현재 모델(`scripts/build-louvre-glb.mjs`)의 배치입니다. **새 모델도 이 배치를 유지합니다.**

| 항목 | 값 |
|---|---|
| 안뜰 바닥 높이 | y = 0.3 |
| 층 높이 | 1층 0.3–9.2, 2층(피아노 노빌레) 9.2–17.2, 다락층 17.2–23.2, 처마 23.2 |
| 외벽 창 간격(한 칸) | 6.2 m |

## 5. Higgsfield 무제한 이미지로 만들 텍스처

- 프롬프트 공통 규칙: *"seamless tileable texture, orthographic, flat even lighting, no shadows, no perspective, no vignette, photographic"*
- 여러 장은 `generate_image_batch` → `jobs_wait` → `show_generation_by_ids` 순서로 한 번에 처리합니다.

## 6. 3D Jutsu 작업 순서 (단계마다 저장하고 렌더로 확인)

- 프로젝트 이름: **"Musée du Louvre"** (`scene_builder_3d_create_project`를 한 번만 부르기)
- 객체 이름은 역할로 짓습니다(`HERO_pyramid`, `WING_richelieu_court`, `PAV_horloge`, `HALL_napoleon`, `ENV_plaza` 등). 재료는 4절의 이름만 씁니다.
- **같은 모양의 반복(외벽 칸, 도머 창, 굴뚝, 창)은 블렌더의 링크 복제(Alt+D, `object.data`를 공유)로 만듭니다.** 그래야 파일이 가볍고, 나중에 한 곳만 고치면 전체가 바뀝니다.
- 확인용 렌더는 **EEVEE, 960×540, 낮은 샘플**로 합니다. 마지막 확인만 Cycles 64샘플로 합니다.
- 확인 시점 카메라(블렌더 좌표, Z가 위):
  - `CAM_aerial_sw`: 위치 (−250, −235, 150) → 목표 (−20, 0, 10) — 뷰어의 기본 시점
  - `CAM_aerial_ne`: 위치 (420, 330, 220) → 목표 (60, 0, 10)
  - `CAM_pyramid_high`: 위치 (−60, −90, 70) → 목표 (0, 0, 5) — 유리 너머로 홀이 보이는지 확인

| 단계 | 할 일 | 확인 기준 |
|---|---|---|
| 1 | 카메라 3대, 작업 조명(Sun 하나, 약한 보조광), 바닥(`ENV_plaza`, 정원 영역) | 바닥이 x −500~290을 덮음 |
| 2 | **건물 덩어리**: 3절의 배치대로 모든 동과 파빌리옹을 상자 + 맨사드 지붕 형태로 | 위에서 내려다본 평면이 3절의 표와 일치(쿼리로 치수 확인) |
| 3 | **외벽 한 칸 모듈**: 1층 아치, 2층 창과 페디먼트, 다락층 창, 벽기둥, 층 띠, 코니스, 발루스트레이드. 창은 벽에서 0.4 m 들어가게 | `CAM_pyramid_high` 렌더에서 창의 깊이감이 보임 |
| 4 | 모듈을 모든 외벽에 배치(링크 복제). 지붕에 도머 창과 굴뚝 | 동마다 칸 수가 길이 ÷ 6.2와 맞음 |
| 5 | **파빌리옹**: 시계탑(롤로주), 리슐리외, 드농, 쉴리, 몰리엥, 튀르고, 다뤼, 콜베르, 마르상, 플로르. 네모 돔, 랜턴, 조각 페디먼트, 카리아티드는 덩어리로 | 최고 높이 45–60 m |
| 6 | **쿠르 카레와 콜로나드**: 안뜰 네 면, 동쪽 바깥 면의 쌍기둥 콜로나드 | 안뜰 (198, 40) 지점이 바닥 높이 |
| 7 | **피라미드**: 마름모 603장 + 삼각형 70장 유리, 스테인리스 노드, 안쪽 케이블 트러스. 작은 피라미드 3개, 연못 7개, 분수 | `Pyramid_Glass` 높이 21.6 m |

## 9. 나폴레옹 홀 사양 (근사값)

멀리서는 **유리 피라미드 너머로 보이는 부분**만 중요합니다. 특히 밤에 홀이 빛날 때 잘 보입니다. 그래서 보이는 부분에 집중합니다.

- 위치: 피라미드 바로 아래. 홀 천장(광장 바닥)은 y 0.3, **홀 바닥은 y ≈ −9.0**입니다.
- 평면: 약 **70 × 70 m 정사각형**, 원점 중심. 단, 광장 바닥을 뚫는 곳은 **피라미드 바닥(35.4 m 정사각형)뿐**입니다. 그 바깥은 천장(`Hall_Concrete`, 격자 무늬 천장)으로 막힙니다.
