# 3D 모델 파일

랜드마크 3D 뷰어가 불러오는 파일을 이 폴더에 둡니다. 뷰어는 아래 순서로 찾아서 처음 발견한 것을 보여줍니다.

1. **가우시안 스플랫** (실제 사진으로 만든 실사 장면) — `eiffel.spz`, `eiffel.sog`, `eiffel.ksplat`, `eiffel.splat`, `eiffel.ply` 순서
2. **GLB 모델** — `eiffel.glb`
3. 둘 다 없으면 코드로 만든 임시 모델

| 파일 이름 (확장자 제외) | 랜드마크 |
|---|---|
| `eiffel` | Tour Eiffel |

## 가우시안 스플랫 파일 조건

- **형식**: `.spz`, `.sog`, `.ksplat`, `.splat`, `.ply`(3DGS 표준 또는 압축 PLY) 중 하나.
- **용량**: GitHub는 100 MB를 넘는 파일을 거부합니다. 가능하면 50 MB 이하로, 큰 `.ply`는 압축 형식(`.spz`, `.sog`, 압축 PLY)으로 변환하세요. 클수록 처음 열 때 오래 걸립니다.
- **라이선스**: 재배포가 허용된 것(CC0, CC BY 등). CC BY라면 `src/viewer-registry.ts`의 `credit`에 제작자와 출처를 적어야 합니다.
- **범위**: 에펠탑이 장면의 중심에 있고 주변이 너무 넓지 않은 것이 좋습니다. 뷰어는 장면의 높이를 탑 높이에 맞추고 바닥 중앙에 세웁니다.

방향이 뒤집혀 보이거나 크기·위치가 어긋나면 `src/viewer-registry.ts`의 `splat` 항목에서 조정합니다.

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `rotation` | x, y, z축 회전(도) | `[180, 0, 0]` (대부분의 촬영 데이터는 위아래가 뒤집혀 있음) |
| `scale` | 장면 단위 1을 몇 미터로 볼지 | 장면 높이를 탑 높이에 자동 맞춤 |
| `offset` | 중앙 정렬 후 옮길 거리(미터) | `[0, 0, 0]` |
| `background` | 배경색 | `#0b0e14` |

스플랫은 촬영 당시의 빛이 색에 그대로 들어 있어서, 이 모드에서는 낮/밤 전환과 조명 효과가 없습니다.

## GLB 모델 파일 조건

- **형식**: glTF 바이너리(`.glb`) 한 개. 텍스처가 파일 안에 포함된 것. Draco·Meshopt 압축 지원.
- **용량**: 30 MB 이하 권장.
- 크기·방향·위치는 뷰어가 자동으로 맞춥니다 (높이를 실제 높이로 맞추고 바닥 중앙에 세움).
- 현재 들어 있는 `eiffel.glb`는 `npm run model:eiffel`로 생성한 파일입니다.
